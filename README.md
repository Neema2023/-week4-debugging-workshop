# Week 4: Debugging Workshop

## Overview

This project is part of my Week 4 JavaScript practice. The goal is to learn how to identify, understand, and fix JavaScript errors using Google Chrome DevTools.

## What I Practised

- Reading and understanding JavaScript errors in the Console.
- Identifying and fixing common JavaScript bugs.
- Using breakpoints and conditional breakpoints.
- Stepping through code to understand how it executes.
- Inspecting variables using the Scope panel.
- Viewing and inspecting Local Storage.
- Documenting errors, solutions, and debugging evidence.

## Project Files

| File or Folder | Description |
|---|---|
| `errors.html` | Contains six JavaScript debugging exercises. |
| `errors.md` | Explains the six errors, their causes, and their fixes. |
| `buggy-cart.js` | Contains the corrected shopping cart exercise. |
| `screenshots/` | Contains screenshots showing my debugging process. |

## Tools and Technologies

- HTML5
- JavaScript
- Google Chrome DevTools
- Visual Studio Code
- Git and GitHub

## What I Learned

Through this workshop, I practised reading error messages, tracing code execution, inspecting variables, and correcting common JavaScript mistakes. I also learned how to use breakpoints and Local Storage in Chrome DevTools.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `errors.html` in Google Chrome using Live Server.
4. Open Chrome DevTools by pressing `F12`.
5. Use the Console and Sources panels to practise debugging.
