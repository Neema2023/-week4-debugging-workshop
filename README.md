# Week 4 - Debugging Workshop


The goal is to practise debugging JavaScript using Chrome DevTools.

## What I Will Practise

- Reading JavaScript errors in the Console.
- Finding and fixing bugs.
- Using breakpoints and stepping.
- Inspecting variables with Scope and Watch.
- Inspecting Local Storage.

## Project Files

- `errors.html` - Six JavaScript debugging exercises.
- `errors.md` - Explanations and fixes for the six errors.
- `buggy-cart.js` - Shopping cart debugging exercise.
- `screenshots/` - Screenshots showing debugging evidence.

- HTML
- JavaScript
- Google Chrome DevTools
